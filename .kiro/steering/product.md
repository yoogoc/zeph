# Product Overview

Zeph is a native desktop API testing application built with Rust and GPUI. It provides a modern, performant interface for testing HTTP services, managing API workspaces, and organizing requests into folders.

## Core Features

- **Workspace Management**: Organize API services and schemas into workspaces
- **HTTP Request Testing**: Send HTTP requests with customizable headers, body, and parameters
- **Folder Organization**: Group related services with shared configuration (common headers, search parameters)
- **Environment Support**: Manage multiple environments with base URLs and variables
- **Internationalization**: Built-in support for English and Chinese (zh-CN default)
- **Schema Management**: Store and manage API schemas alongside services

## Target Users

Developers and QA engineers who need a fast, native desktop tool for API testing and documentation, similar to Postman or Insomnia but with a focus on performance and native UI.
